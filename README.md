# Power BI Data Visualization & Business Intelligence Portfolio

Welcome to my Power BI portfolio repository! This collection showcases my expertise in transforming raw datasets into interactive, insightful business intelligence dashboards, utilizing Power Query, data modeling, DAX measures, and custom visual layouts.

---

##  Technical Skills Demonstrated
* **Data Transformation & ETL:** Data cleaning, merging, and shaping using Power Query.
* **Data Modeling:** Building star schemas, handling relationships, and establishing cardinality.
* **DAX (Data Analysis Expressions):** Writing calculated columns, measures, and time intelligence functions.
* **Dashboard Design:** Crafting interactive visuals, filters, slicers, and executive-ready layouts.

##  How to View These Files
Since Power BI files (`.pbix`) require Power BI Desktop to view interactive features:
1. Download [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free).
2. Download the `.pbix` file of interest from the relevant folder above.
3. Open the file locally to explore the data models, DAX formulas, and interactive dashboard pages.
